# modulos/

Un módulo por funcionalidad del negocio, cada uno con `dominio/`, `aplicacion/`, `infraestructura/`, `presentacion/`, su `*.module.ts` (composición) e `index.ts` (API pública). Ver `Docs/arquitectura/arquitectura-limpia.md`, sección 4.1.

`salud/` es el módulo de ejemplo de la estructura: no tiene infraestructura propia porque no toca la base de datos.
