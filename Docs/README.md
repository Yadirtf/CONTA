## Orden de lectura para alguien nuevo (persona o agente)

1. Plan del proyecto (resumen y alcance).
2. Arquitectura limpia.
3. Guía del coordinador, secciones 2, 3 y 7.
4. La historia del backlog en la que va a trabajar.
